# Birr

A private personal-finance tracker for Ethiopia that runs as a Telegram bot + Mini App. It ingests telebirr (`127`) and CBE SMS, parses them into transactions, and shows balances, budgets and insights in ETB.

## Layout

```
apps/server      Hono API + grammY bot + SMS ingest + scheduled jobs (one process)
apps/miniapp     React + Vite + Tailwind Mini App
packages/parser  SMS templates per sender, fixtures, tests
packages/core    Pure logic: reconciliation, transfer matching, budgets, Ethiopian calendar…
packages/shared  Shared types and default categories
drizzle/         SQL migrations (generated by drizzle-kit)
```

### Why SQLite

Birr has one or two users and a few thousand rows a year. SQLite (WAL mode) handles that with no separate server to run, patch or secure, and a backup is copying one file. FTS5 covers full-text search. Drizzle keeps the schema portable if Postgres is ever needed.

## Local development

Requires Node ≥ 22 and pnpm (`npm i -g pnpm`).

```sh
pnpm install
cp .env.example .env         # fill BOT_TOKEN, ALLOWED_TELEGRAM_IDS, DATA_ENCRYPTION_KEY
pnpm db:migrate
pnpm dev                     # API+bot on :8787 (polling), Mini App on :5173
pnpm test
```

Telegram only opens Mini Apps over HTTPS. In dev, tunnel the Vite port (it proxies `/api` to the server):

```sh
cloudflared tunnel --url http://localhost:5173
```

Put the printed `https://….trycloudflare.com` URL in `MINIAPP_URL`, restart, and send `/start` to your bot.

## Schema changes

Edit `apps/server/src/db/schema.ts`, then `pnpm db:generate`. Migrations run automatically at server start.
